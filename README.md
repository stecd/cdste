# Personal Website.

### Set up
I am using [harp](http://harpjs.com/) as the static website generator tool.

To serve:
```
harp server
``` 

To compile:
``` 
harp compile ./ ./docs

```

### Tools I am using:
- The static web server 
- masonry layout: https://github.com/desandro/colcade
